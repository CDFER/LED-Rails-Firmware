Kea Studios Setup

Wi-Fi setup and updates for your Live Train Map.

  1. Plug your map into a USB port on your computer using the supplied USB Cable.
    Note: For setup you can only use the USB port on the left side on Auckland and Melbourne maps.
  2. Make sure you have selected the correct city and version of your map below.
    You can check the version of your map by looking for the label on the backside of the map.
  3. Click "Connect" and select the correct COM port.
    Look for the COM port labeled as "USB JTAG/serial debug unit".
  4. Select "Connect to Wi-Fi" and follow the prompts.
    Installing the latest Firmware is optional.
Sorry, your browser does not support Web Serial. Please use Chrome or Edge. This tool requires HTTPS. Please use a secure connection.

New Features

V1.3.0

  • Melbourne maps are now here!

    • Features full Realtime live train tracking across the Metro network, now with the ESP32-S3 chip supported (rather than the ESP32-C3 on AKL and WLG).

V1.2.2

  • Auckland maps now have a 4th mode that shows the Realtime live trains but hides the purple (Out of Service) trains. Access this mode by long pressing the power button to cycle through modes.

V1.2.1

  • The offline Timetable Mode I added for Wellington is now available for Auckland maps. You can access the timetable modes by long pressing the power button.
  • The Timetable modes show the October 2025 weekday timetable. If Wi-Fi is available, the map shows the timetable for the current time of day. The second timetable mode shows the same timetable but at 600x speed.
